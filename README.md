# 🏦 Loan Approval System

An AI-powered smart loan decision platform that predicts loan approval status using 4 Machine Learning classification models.

## 🚀 Live Demo
**[Visit the App](https://classification.streamlit.app)**

## 📊 Features
- Real-time loan approval prediction
- Interactive applicant form
- 4 ML models with live training at startup
- Beautiful, professional UI with custom CSS

## 🤖 Models Included
| Model | Type | Accuracy |
|---|---|---|
| Logistic Regression | Linear | ~81% |
| Decision Tree | Tree-based | ~78% |
| Random Forest | Ensemble | ~86% |
| Naive Bayes | Probabilistic | ~75% |

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- Custom CSS Styling

## 📂 Project Structure
```
Classification/
├── streamlit_app.py              # Main Streamlit application
├── Loan_approval_data_2025.csv   # Training dataset
└── requirements.txt              # Dependencies
```

## 📦 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
